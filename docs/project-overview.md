# AI Content Summarizer Using n8n and Gemini API

## Project Overview

AI Content Summarizer is an automation workflow developed using n8n, Google Sheets, and Google's Gemini API. The system automatically reads text content from a Google Sheet, generates concise summaries using Artificial Intelligence, and updates the corresponding spreadsheet row with the generated summary.

The project demonstrates workflow automation, API integration, OAuth2 authentication, data processing, and cloud-based productivity automation.

## Problem Statement

Manually summarizing large amounts of text is time-consuming and repetitive. Organizations and individuals often need quick summaries of articles, reports, notes, and content stored in spreadsheets.

This project automates the summarization process, reducing manual effort and improving productivity.

## Technologies Used

* Google Gemini API

* OAuth2 Authentication

## Workflow Architecture

1. Read content records from Google Sheets.
2. Send content to Gemini API through HTTP Request.
3. Generate AI-powered summaries.
4. Extract the summary response from the API output.
5. Update the corresponding row in Google Sheets.
6. Store generated summaries automatically.
